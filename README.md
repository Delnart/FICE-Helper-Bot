## 🚀 Про проєкт

**FICE Helper** — це комплексне цифрове рішення для студентських груп. Замість десятка розрізнених таблиць, закріплених повідомлень та блокнотів, проєкт об'єднує весь навчальний процес в одному зручному просторі прямо в Telegram:

- **Telegram-бот**: блискавичні команди (`/now`, `/today`, `/tomorrow`, `/left`), нагадування про пари та дедлайни, привітання з днем народження та маршрутизація повідомлень у теми (topics).
- **Telegram Mini App**: повнофункціональний веб-інтерфейс із розкладом, електронними чергами, журналом відвідуваності, домашніми завданнями та списком викладачів.

## ✨ Можливості

### 📅 Інтелектуальний розклад пар
- **Авто-синхронізація з Campus KPI**: розклад оновлюється кожні 12 годин у фоновому режимі та автоматично завантажується під час прив'язки групи.
- **Підтримка I та II тижня**: автоматичне визначення поточної парності тижня.
- **Прямі посилання на онлайн-пари**: миттєвий перехід до конференцій Zoom, Google Meet або Microsoft Teams.
- **Швидкі команди в боті**: `/now` (поточна та наступна пара), `/left` (хвилини до завершення), `/today` та `/tomorrow`.

### 🎯 Вибіркові дисципліни
- **Єдина сутність дисципліни**: лекції, практики та лабораторні заняття автоматично групуються в одну вибіркову дисципліну.
- **Збереження вибору студентів**: при зміні розкладу або зміщенні часу пар у Campus KPI всі вибіркові дисципліни та вибір студентів залишаються недоторканими.
- **Управління для старости**: легке позначення або вилучення дисциплін з вибіркових.

### 🔢 Електронні черги для захисту робіт
- До 50 слотів на одну чергу із захистом від повторного запису.
- Можливість запису, звільнення та **інтерактивного обміну місцями** між студентами.
- Автоматичне відкриття черги перед початком пари за розкладом.

### 📚 Дисципліни та корисні посилання
- Централізована сторінка для кожного предмета: викладачі, контакти, правила зарахування.
- Репозиторій посилань: Moodle, Google Classroom, хмарні диски, конспекти та рейтингові таблиці.

### 📝 Домашні завдання
- Перелік актуальних завдань з дедлайнами та описами.
- Відмітки про виконання для кожного студента.
- Автоматичні чат-нагадування за 24 години до дедлайну.

### 📋 Журнал відвідуваності
- Швидке відмічання присутніх старостою або заступником в один клік під час пари.
- Персональний журнал для кожного студента з фіксацією статусів: присутній, запізнився, відсутній (поважна/неповажна причина).

### 🔔 Сповіщення та підтримка гілок чату (Topics)
- Сповіщення надсилаються у груповий чат або в окремий топік після виклику команди `/migrate`.
- Нагадування за 10 хвилин до початку кожної пари із посиланням на зустріч.
- Автоматичні привітання одногрупників з днем народження.

### 👨‍🏫 Кабінет викладача
- Окремий інтерфейс для викладачів: розклад занять по всіх закріплених групах, доступ до журналів та черг без зайвих студентських елементів.

## 🤖 Команди бота

| Команда | Контекст | Опис |
| :--- | :--- | :--- |
| `/start` | Особисті | Початок роботи, відкриття головного меню та Mini App |
| `/now` | Всі чати | Інформація про поточну пару та наступне заняття |
| `/left` | Всі чати | Скільки хвилин залишилося до кінця поточної пари |
| `/today` | Всі чати | Повний розклад занять на сьогодні |
| `/tomorrow` | Всі чати | Повний розклад занять на завтра |
| `/verify` | Група (староста) | Прив'язка чату до академічної групи та імпорт розкладу |
| `/migrate` | Група (староста) | Переприв'язка групи або зміна цільової гілки (топіку) для сповіщень |
| `/support` | Особисті | Зв'язок з адміністраторами підтримки сервісу |
| `/help` | Всі чати | Динамічна довідка з командами, доступними поточному користувачу |

## 🏗️ Стек технологій

- **Backend**: [NestJS 10](https://nestjs.com/), [Grammy](https://grammy.dev/) (Telegram Bot framework), [Mongoose](https://mongoosejs.com/) (MongoDB ODM), `@nestjs/schedule` (Cron jobs).
- **Frontend**: [Next.js 14](https://nextjs.org/) (App Router), [Tailwind CSS](https://tailwindcss.com/), [TanStack React Query](https://tanstack.com/query), [Day.js](https://day.js.org/).
- **Database**: [MongoDB 7.0](https://www.mongodb.com/).
- **Shared Package**: спільні TypeScript-типи, валідатори та перерахування (`@fice/shared`).
- **Контейнеризація & Деплой**: Docker, Docker Compose, GitHub Actions CI/CD.

## 🛠️ Швидкий старт

### Вимоги
- **Node.js** ≥ 20.0.0
- **npm** ≥ 10.0.0
- **MongoDB** 7.x (локально або через Docker)

### 1. Клонування репозиторію
```bash
git clone https://github.com/Delnart/FICE-Helper-Bot.git
cd FICE-Helper-Bot
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Налаштування змінних середовища
Створіть файл `.env` на основі прикладу:
```bash
cp .env.example .env
```
Заповніть основні параметри (токен бота, підключення до MongoDB, секрет JWT тощо). Детальніше про локальний запуск із тунелем читайте в [docs/LOCAL_SETUP.md](docs/LOCAL_SETUP.md).

### 4. Запуск у режимі розробки
```bash
npm run dev
```
- Backend API: `http://localhost:3000/api`
- Frontend Mini App: `http://localhost:3001`

## 🚢 Деплой через Docker

### Збірка та запуск локального стеку
```bash
npm run docker:up
```

### Продакшн деплой через пребілд-образи (GHCR)
```bash
# Локальна збірка і пуш у GitHub Container Registry:
./scripts/build-and-push.ps1

# На сервері:
docker compose -f docker/docker-compose.prod.yml --env-file .env up -d
```

## 🔒 Безпека

- **Аутентифікація Telegram**: `initData` від Telegram WebApp валідується за допомогою криптографічного підпису HMAC-SHA256 з перевіркою терміну дії токена (TTL 24h).
- **JWT сесії**: запити авторизуються через Bearer токен, а заголовок `x-group-id` ізолює контекст прав на рівні кожної окремої групи.
- Детальніше про заходи безпеки читайте у [SECURITY.md](SECURITY.md).
